# Softy Pinko Docker

This repository contains the Docker tasks for the Softy Pinko application.

## Tasks

- `task0`: Build an Ubuntu image.
- `task1`: Run a Flask API in a container.
- `task2`: Serve the front end with Nginx.
- `task3`: Connect the front end to the API.
- `task4`: Run the services with Docker Compose.
- `task5`: Route traffic through an Nginx reverse proxy.
- `task6`: Scale the API service and balance requests.

## Requirements

Docker Desktop and Docker Compose.
